Aplicación de escritorio para Windows 10/11 de 64 bits.

Descarga y ejecuta **SATH-Escritorio-1.0.1-Instalador.exe** en la sección **Assets / Recursos** de esta página.

- Formularios SATH con vista previa A4, PDF e impresión con o sin fondo.
- Documentos con guardado automático y búsqueda.
- Plantillas editables con campos que se pueden arrastrar.
- Imágenes JPG/PNG como archivos locales, sin Base64.
- Respaldos completos y restauración.

El instalador es por usuario. Los datos e imágenes se guardan en la carpeta `datos`, junto al ejecutable. Conserva preferiblemente la ubicación propuesta y crea respaldos externos.

El instalador no tiene firma digital. La instalación, actualización, desinstalación e impresión física necesitan una comprobación final en un equipo Windows real.

El código y las instrucciones de uso están en el README del repositorio.
